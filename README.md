# Om Shree Foods and Catering Services

A Next.js e-commerce and catering website for Om Shree Foods and Catering Services.

## Features

- Product catalogue and cart
- Prepaid checkout with Razorpay
- Shipping quotes and shipment integration
- Admin dashboard for products, categories, and orders
- Prisma with PostgreSQL
- Supabase storage and database services

## Local development

```bash
npm install
npm run dev
